# 構成・データ保護

正規URLは https://sg-study-deck.dengana-10011212.workers.dev/ 。個人用アプリとして、バックアップを使う全端末は同じ専用復旧キーで接続します。

| 層 | 役割 | 保存内容 |
|---|---|---|
| PWA / Service Worker | 画面、テーマ、オフライン | 配布静的ファイル。API・Cookie・音源をキャッシュしない |
| IndexedDB | 毎回答後の即時保存 | 独立問題カタログ、追記回答、セッション、設定、復習状態、音源Blob、送信待ち、退避記録 |
| Web Audio | 継続再生・フェード | DOM外で維持する2プレーヤー、独立Gain、ダッキング、リミッター |
| Workers | 認証・保存・復元API | オリジン検査、サイズ制限、形式・ハッシュ検査 |
| D1 | クラウド永続保存 | 復旧キー/端末トークンのハッシュ、端末情報、JSONバックアップ最新5世代 |

## 履歴

問題の恒久IDとrevisionは、配布パックと履歴に個別に記録します。パック更新はカタログのみを書き換え、回答を削除しません。回答IDはセッションIDと回答番号から作り、二重タップを1件へ収束させます。回答・セッション・復習状態・変更番号を同じトランザクションで保存してから次へ進みます。

初見は初回の実回答だけ。表示だけでは既出になりません。過去の最初の回答から集計するため、復習やJSON復元後も初見の結果を変えません。期間集計にも全履歴の初回IDを使います。分野は回答時点のタグを記録します。

学習時間は表示中・未停止・直近60秒以内に操作した時間。10秒ごとと画面操作時にセッションを保存。活動時間は各セッション開始日へ集計します。クラッシュで直近10秒程度の活動時間が未保存になる場合がありますが、回答記録は回答ごとに確定しています。

## バックアップ

前回の成功から48時間以上経過し、未送信の変更があるとき、起動・オンライン復帰・再表示・セッション終了時に送信します。閉じたアプリでの定時処理は行いません。無変更の手動操作も新世代を作りません。

送信待ちは操作ID、完全JSON、SHA-256、対象変更番号、基準となる最新世代IDを端末に保持。通信失敗後も同じ操作IDで再送します。保存後にJSONを再取得し、クライアントでも完全ハッシュと形式を検証してから確定。確定した世代だけを最新5件に整理します。古い未完了処理は新しい保存を塞ぎません。

送信中の追加変更は未送信として残します。別端末の保存と競合すると上書きを停止し、履歴の確認を求めます。自動マージはしません。初回接続時に既存履歴がある場合も、復元か新世代の保存を明示的に選びます。

復元はプレビュー時の端末変更番号を照合し、既存記録を退避してから同じトランザクションで置換。途中失敗で現在の記録と退避を消しません。音源Blobと問題カタログは置換しません。追加問題は元のパックから別途再追加できます。

## 認証

アプリ専用256bit復旧キーを、初期化時に別ファイルへ作成。D1にはアプリID付きSHA-256のみ保存。ログイン時はランダム256bit端末トークンを `__Host-sg-study-deck` Secure / HttpOnly / SameSite=Strict / Path=/ Cookieで発行し、D1にハッシュを保存します。Cookieは利用時に400日へ更新し、サーバーには端末トークンの一律失効期限を設けません。ブラウザ側での永久保持は保証できません。

他端末の名称変更、個別/全端末取消、復旧キー変更には復旧キーを再確認。キー変更は全端末を取り消します。生のキーと通行証はIndexedDB、JSON、ソース、ログへ書きません。認証試行はIPの短期ハッシュで5分あたり8回に制限。POSTは同一オリジンだけを許可します。CORSによる外部サイト許可は設けません。

CSP、クリックジャッキング防止、nosniff、noindexを配信。外部の広告・分析・CDN・音源は使用しません。音楽は本人が追加した端末Blobのみです。

## 読み上げ（v1.1.0）

`public/js/speech.js` のSpeechReaderが、問題文と選択肢を日本語で順に読み上げます。端末音声を優先し、利用可能な日本語音声がない場合は案内を表示します。長文を区切って渡し、各読み上げの識別番号で取消後の古いイベントを無視します。回答・一時停止・非表示・ページ終了・画面移動で音声キューを取り消します。

読み上げはゲーム画面のDOM再描画から独立しています。AudioEngineは読み上げと効果音の音量抑制を別々に管理し、読み上げ中に効果音が終了してもBGM音量が先に戻らないようにします。BGMの再生位置は変えません。

`speechAuto` / `speechOptions` / `speechRate` / `speechVolume` / `speechDuck`を既存の設定と同じIndexedDB・JSON・クラウドで保存します。旧設定は読み込み時に初期値を補い、回答履歴・音源・変更番号は更新しません。APP_ID、manifest ID、DB名、DB版、バックアップ形式版は維持しています。
