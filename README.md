# SG Study Deck

情報セキュリティマネジメント試験を、3つの世界で学ぶスマートフォン向けPWA。Made by YUU。アプリ v1.5.0、実装仕様 v1.1。

公開URL: https://sg-study-deck.dengana-10011212.workers.dev/

ソース: https://github.com/yuuuh26/sg-study-deck

## 使い始める

Android Chromeで公開URLを開き、必要に応じてメニューからホーム画面に追加します。初期状態はBGM未登録で正常に遊べます。読み上げは問題画面の「問題を読み上げ」、または「自動 ON」から開始。「設定 → 問題の読み上げ」で内容・速度・音量を調整し、「音声を試す」で端末の日本語音声を確認します。自動読み上げは初期OFF。端末に保存された日本語音声を優先しますが、声質・発音・オフライン可否は端末の音声に依存します。

ホームの「クイックスタート」で問題数を1〜100問から指定します。初期値は5問。問数は設定画面でも変更でき、収録数を超える場合は出題できる件数までになります。

選択肢を選べないときは「分からない・あとで復習」を押します。選択肢を当てずに記録でき、未正解として正答率・重点復習へ反映します。初見の「分からない」は初見の未正解として保持し、あとで正解しても書き換えません。

終了後の「あとで聞く問題一覧」には、誤答と「分からない」をまとめて表示します。「まとめてAIに聞く」は問題全文・全選択肢・自分の回答・正解・解説・出典を一括で共有します。ホームの「最近の冒険 → 一覧を見る」から直近3回の終了結果を開き直せます。

「AIに詳しく聞く」はAndroidなどの共有画面へ直接進みます。AIが共有先にあれば選択して送信してください。共有に未対応・失敗した場合は、質問文をコピーしてChatGPTなどへ貼り付ける画面を表示します。共有キャンセルで学習履歴は削除しません。模試は終了後のみ利用できます。

読み上げは「ア」などの記号だけを読み、約0.4秒の間を置いて選択肢本文を読みます。

音楽は「設定 → BGMライブラリ」で追加。端末へ保存し、問題の切替では再生を止めません。

クラウドは「設定 → クラウドバックアップ」で、このアプリ専用の復旧キーを貼り付けて接続します。復旧キーは別の私用ファイルで保管してください。コード・GitHub・画面の共有には含めないでください。

## 実装

- NEON BLITZ / BOSS RAID / CYBER DEFENSE。正解の衝撃波・粒子・ダメージ・シールド、5/10/20コンボ、XP、レベル。
- 問数を選べるクイックスタート、エンドレス、苦手克服、復習予定、初見チャレンジ、本番形式の模試エンジン。
- 回答の即時判定とIndexedDBへの原子的保存。保存失敗時は自動進行しません。誤答時は全選択肢の解説を表示し、手動で進行。
- AIへの個別・一括質問文生成と、直接共有。未対応時はコピーへ切替。誤答・分からないの終了後一覧と保存済み結果の再表示。質問文はオフラインでも生成できます。
- 初見正答率と全回答正答率を分離。初回回答は一度だけ。分野、日/週/月、日本時間、活動中の学習時間を集計。
- 音楽の追加、改名、削除、並替、お気に入り、テーマ割当、リピート/シャッフル、前後移動、シーク、独立音量。2チャネルのWeb Audio GainNodeで滑らかに切替。
- 問題文・4択の日本語読み上げ。手動開始/停止、自動読み上げ、問題文のみ、0.7〜1.5倍、独立音量、音声テスト。読み上げ中はBGMを滑らかに下げ、終了後に戻します。回答・一時停止・非表示・ホーム移動で読み上げを停止。
- 問題間でBGM継続、終了時は標準2.5秒、一時停止は0.8秒のフェード。フェード中の再開と短時間の連続曲変更に対応。
- 48時間・変更ありの場合だけ自動バックアップ。手動保存、検証済み最新5世代、期限による自動削除なし、JSON入出力、復元前の安全退避。
- 専用manifest ID、192/512/maskableアイコン、オフラインキャッシュ、公開URLコピー、検索エンジンへのnoindex。

## 初期問題と制限

初期収録は2025・2026年度のIPA公開問題から、原典と公式解答を照合した科目A 22問です。著作権はIPAに帰属。解説は独自編集し、各選択肢の理由、出典、根拠、表・図の文章化等の改変を表示しています。利用条件は https://www.ipa.go.jp/shiken/faq.html を参照。

v1.4.0では、一次資料で正解・全選択肢の解説を照合した独自の実用入門・予想問題32問を追加。v1.5.0で実用入門②32問を追加し、合計86問です。認証、暗号・ハッシュ、アクセス制御と隔離、脆弱性対策を各8問収録。IPAの公式問題・解説とは区別して表示します。2016〜2019年の問題と未検証問題は未収録です。

**本番形式は科目A48問＋科目B12問が揃うまで開始できません。** 初期問題はA22/B0。選択肢を減らした架空の公式問題で穴埋めせず、画面に不足を表示します。模試の選択・120分タイマー・終了後の答え合わせはテスト用データで検証済みです。公式のIRT評価点・合否は再現しません。

画像ファイルを添付する問題パックはv1では未対応です。文章化した表・図と改変表示を利用します。Android実機でのインストール、振動、実際の音源とイヤホンによる聴感の最終確認は未実施です。

## 開発・検証

Node.js 22.13以降（node:sqliteを使用）、Python 3、npm。

```bash
npm install
npm test
npm run check
npm run build
npx playwright install chromium
npm run test:browser
```

Chromiumを独自に配置する環境では `SG_CHROMIUM_PATH`、Playwrightやfake-indexeddbの独自配置には `SG_PLAYWRIGHT_PATH` / `SG_FAKE_IDB_PATH` を使用できます。これらは任意で、通常はnpm依存を読み込みます。

`tests/production-smoke.py` は私用の復旧キーファイルを `SG_RECOVERY_KEY_FILE` に指定した場合だけ実行してください。名前付きの検証用端末・バックアップを作るため、一般CIでは実行しません。実行後は生成されたIDだけを管理者が削除します。

構成、検証結果、問題追加方針は `docs/architecture.md` / `docs/verification.md` / `docs/question-data.md` を参照。

## 配信

正規の配信元はCloudflare Workersです。画面と `/api/` を同じオリジンで配信し、D1へ保存します。GitHubはソース管理用。GitHub Pagesから別オリジンのWorkersへCookie認証を送る構成は採用していません。Pagesを入口にする場合も、正規URLへ移動してください。オリジンを変えるとIndexedDBと保存した音源は別領域になります。

通常の再公開は `npx wrangler deploy`。`wrangler.jsonc` のD1 bindingはこのアプリ専用です。既存DBの削除や認証キーの上書きはしないでください。初回配信では、接続済みCloudflare APIから `npm run build` で生成した静的ファイルを内包するWorkerをアップロードしています。両方とも同じアプリ・同じAPI・同じD1を使います。

## 取り扱い

音源本体、端末の通行証、復旧キーはJSONバックアップ・ソース配布へ含めません。音源本体は端末内のみ。サイトデータ削除に備え、クラウドとJSONを併用してください。復元前の記録は自動削除せず、設定から書き出せます。

ソース・問題データ・テスト・検証報告は `yuuuh26/sg-study-deck` の `main` ブランチで管理します。再公開時も上記のCloudflare Workers URLを使用します。

## 実用から学ぶ（v1.4.0）

ホームの4カードは「認証 → 暗号・ハッシュ → アクセス制御と隔離 → 脆弱性対策」の順。各カードはその分野の入門問題だけを出し、未回答は基本から順に学べます。上の問題数（1〜100問、既定5）を使い、在庫数まで出題します。一度回答した問題は復習として扱い、初見正答率は書き換えません。クイックスタートの「出題する分野」では、過去問も含めた任意の分野を選択可能です。

問題は別JSONで配布し、学習履歴・音源・PWA ID・DBスキーマ・認証を維持。入門問題は模試のA48問／B12問の在庫に数えません。SGの基礎知識に対応し、サンドボックスはシラバス用語例に名称の明記がない関連知識として説明します。詳細と全問の根拠は `docs/practical-learning.md` に記載。


## 専門用語に慣れる実用入門②（v1.5.0）

①の次は「ネット・ブラウザ → 詐欺・危険ファイル → クラウド・AI → トラブル初動」。各8問、計32問です。TLS・Cookie・OAuth・封じ込めなどの言葉を、身近な場面の問題文に1〜2個入れます。回答後の解説に短い「用語メモ」を表示し、正解時も「解説を表示」で確認できます。誤答・分からないの終了後一覧、問題ライブラリ、個別・一括のAI質問文にも用語メモを含めます。

①と②はホームに別々の入口を設け、それぞれのミックスと結果画面からの再プレイも選んだ段階を保持します。未回答は基本から順に、回答済みは復習として扱います。公式22問と①32問の配布JSONは変更せず、②を独立したパックで追加。以前の学習記録・中断セッション・音源・認証を引き継ぎます。全問と根拠は `docs/practical-learning-2.md` を参照。
